# ClimateOps

ClimateOps is a real-time environmental emergency monitoring
platform that helps detect and respond to natural hazards.

## Overview

The project focuses on floods, droughts, heatwaves, and water
emergencies. It uses environmental data to provide location-based
risks and actionable insights.

## Project Structure

- frontend/ - Frontend application
- backend/ - Backend application
- dev_requirements.md - Development requirements
- frontend.md - Frontend documentation
- plan.md - Project plan
- project_plan.md - Detailed project plan

## Objective

To provide useful environmental risk information and support
better decision-making during natural emergencies.

## Team
